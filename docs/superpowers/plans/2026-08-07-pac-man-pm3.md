# Pac-Man (pm3) Implementation Plan — Authentic Graphics & the Working Tunnel

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Pac-Man's honest-placeholder render with the cabinet's real byte-cited tile/sprite graphics and true hardware palette, fix the broken tunnel (position-wrap + slowdown), and wire the pm2-deferred presentation overlays onto the existing events seam.

**Architecture:** Harness-first — vendor the graphics/colour ROMs under an extended citation gate BEFORE any pixel is decoded (the pm1-2 / pm2-1 lesson). Every decoded tile/sprite/palette is a PURE decoder over the vendored ROM bytes, unit-tested byte-equal to the ROM at test time (the pm2 `wsg-data.ts` precedent), and baked to a committed JS module — zero runtime asset fetch, so no R2 bucket can 404 the graphics away. Only the tunnel task touches `src/core/`; all decode/render is shell-side, preserving the `src/core/` purity invariant. The tunnel fix and the overlays each consume seams pm1 already built (`maze.tileAt` wrap semantics; `events.ts`'s `GameEvent` union).

**Tech Stack:** TypeScript, Node ≥ 22.18 (default `.ts` type-stripping), Vitest (per-app project, `environment: 'node'` — no jsdom, so render decoders are pure and tested without a canvas), Canvas 2D at runtime, the existing `tools/audit/check-citations.mjs` binary-citation gate.

## Global Constraints

- **ROM is canonical, cite don't copy.** Byte source = the MAME `pacman` parent romset (`~/roms/pacman.zip`). Decoder authority = MAME's `gfxdecode` layouts / `PALETTE_INIT` in `src/mame/pacman/pacman.cpp`, cited in `glossary.md`, never pasted. `shaunlebron/pacman` (GPL v3) is a read-only oracle — zero lines copied. MAME is the tiebreaker.
- **Every decoded pixel is byte-cited under the gate.** `node tools/audit/check-citations.mjs` (over `docs/rom-study/claims/graphics.json`) must be green for pm3-3..6 to merge. No hand-drawn "honest-uncited" art.
- **Core stays pure.** Only pm3-2 edits `src/core/` (`maze.ts`, `pacman.ts`, `ghost.ts`, `level.ts`, `game.ts`). `tests/purity.test.ts` scans `src/core/*` source text for DOM/clock/`Math.random`/shell imports — it must stay green. No decode/render code enters `src/core/`.
- **Baked, never fetched.** Decoded graphics live in committed `src/shell/*-data.ts` modules (the `wsg-data.ts` precedent), regenerated by a bake step, with a test asserting byte-equality against a re-decode of the vendored ROM. No runtime `fetch`/asset dependency.
- **Radix trap.** ROM addresses in `pacman.asm` are hex (`#xx`); PROM/ROM offsets in `claims/graphics.json` are decimal byte offsets. Bytes are compared, never parsed.
- **Node version floor is real:** `scripts/` and tests rely on Node ≥ 22.18 default type-stripping (`package.json` `engines`).
- **Commit discipline:** frequent commits; one green test cycle per commit. Each task is its own story branch under the `superpowers` workflow.

```js
/** A full-BYTE binary citation (pm3-1): a graphics ROM/PROM file, a byte
 *  offset, and the run of whole bytes (0..255) expected there. Used for the
 *  tile/sprite ROMs and the two colour PROMs, whose meaning is decoded in JS
 *  (MAME gfxlayout / resistor-DAC) — unlike the WSG waveform PROM, the low
 *  nibble is not the whole story, so the WHOLE byte is compared. */
function isByteCitation(o) {
  return (
    typeof o === 'object' && o !== null && !Array.isArray(o) &&
    typeof o.file === 'string' && o.file.length > 0 &&
    Number.isInteger(o.offset) && o.offset >= 0 &&
    Array.isArray(o.bytes) && o.bytes.length > 0 &&
    o.bytes.every((b) => Number.isInteger(b) && b >= 0 && b <= 255)
  )
}
```

```ts
/** Wrap an actor's horizontal position through the tunnel: on the tunnel row
 *  ONLY (the cabinet's single left<->right wrap point, TUNNEL_ROW), an actor
 *  whose xPx has stepped past either edge reappears at the opposite edge,
 *  modulo the maze pixel width. Off the tunnel row this is a no-op — the walls
 *  make an off-edge xPx unreachable there anyway. Mirrors tileAt's wrap, but
 *  for POSITION: tileAt wraps kind LOOKUPS, this wraps the actor. Call it after
 *  every actor step (pacman.ts / ghost.ts). Pure. */
export function wrapThroughTunnel(actor: { xPx: number; yPx: number }): void {
  if (actor.yPx !== TUNNEL_ROW * TILE_PX) return
  const width = MAZE.cols * TILE_PX
  actor.xPx = ((actor.xPx % width) + width) % width
}
```

- [ ] **Step 3: Implement the resistor-DAC decode in `gfx-rom.ts`** (MAME `pacman_palette`, cited in a header comment — resistances `{1000, 470, 220}` for R/G, `{470, 220}` for B):

```ts
// Weights normalised so all-bits-on = 255, all-off = 0 (MAME compute_resistor_weights).
function weights(res: number[]): number[] {
  const cond = res.map((r) => 1 / r)
  const total = cond.reduce((a, b) => a + b, 0)
  return cond.map((c) => c / total) // fraction of full-scale per bit
}
const RG = weights([1000, 470, 220]) // bits 0,1,2
const B = weights([470, 220])        // bits 0,1 -> PROM bits 6,7
function chan(bits: number[], w: number[]): number {
  return Math.round(255 * bits.reduce((s, b, i) => s + b * w[i], 0))
}
/** Decode a Pac-Man 82s123.7f palette PROM to RGB triples (MAME pacman_palette). */
export function decodePaletteFromProm(prom: Uint8Array): [number, number, number][] {
  return Array.from(prom, (byte) => {
    const bit = (n: number) => (byte >> n) & 1
    const r = chan([bit(0), bit(1), bit(2)], RG)
    const g = chan([bit(3), bit(4), bit(5)], RG)
    const b = chan([bit(6), bit(7)], B)
    return [r, g, b] as [number, number, number]
  })
}
```

```ts
// MAME pacman charlayout (src/mame/pacman/pacman.cpp): 8x8, 2 planes at bit
// offsets {0,4}; each tile is 16 bytes; xoffs/yoffs below reproduce the
// split-nibble layout exactly. Bit 0 of an offset is the MSB of byte 0.
const TILE_BYTES = 16
const TILE_PLANES = [0, 4]
const TILE_X = [8 * 8 + 0, 8 * 8 + 1, 8 * 8 + 2, 8 * 8 + 3, 0, 1, 2, 3]
const TILE_Y = [0 * 8, 1 * 8, 2 * 8, 3 * 8, 4 * 8, 5 * 8, 6 * 8, 7 * 8]
function bitAt(rom: Uint8Array, byteBase: number, bitPos: number): number {
  return (rom[byteBase + (bitPos >> 3)] >> (7 - (bitPos & 7))) & 1
}
export function decodeTilePixel(rom: Uint8Array, tileIndex: number, x: number, y: number): number {
  const base = tileIndex * TILE_BYTES
  let v = 0
  for (let p = 0; p < 2; p++) v |= bitAt(rom, base, TILE_PLANES[p] + TILE_X[x] + TILE_Y[y]) << p
  return v
}
```
