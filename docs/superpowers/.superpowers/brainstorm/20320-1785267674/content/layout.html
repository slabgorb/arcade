B · Every tile lives

6 iframes · all at once

Each tile becomes a window onto its own game. Maximum spectacle — and two hard problems. Six full canvas sims at 60 Hz in one page is six independent game loops competing for one main thread. And a tile is an <a href>: an iframe inside it swallows the click, so clicking the demo would stop launching the game. Both are solvable (poster frames, click-shields), neither is free.

C · Idle takeover

1 iframe · only when idle

The lobby stays exactly as it is today. After N seconds of no mouse or key, the cabinet goes full-bleed into a cycling demo; any input dismisses it instantly. This is literally what the docs promise — "runs an attract-mode demo loop when idle" — and it is the real cabinet's behaviour. Costs nothing while you are choosing. The trade: a visitor who never idles never sees it.

D · Living wallpaper

1 iframe · always on, dimmed

The demo plays full-bleed behind the tiles, dimmed to a backdrop, cycling games. Atmospheric and always present without stealing layout space. But it competes for the same pixels as the existing cabinet chrome — the vector grid floor and its mirrored ceiling would have to go or fight it — and legibility of the tiles over moving content is the whole risk.

Click one, or tell me in the terminal. Mixing is on the table too — A + C (a pane that goes full-bleed once you idle) is a coherent pair.
