# Epic SH4 Context

## Title
Shared-library extraction — lift verified cross-game duplication into src/shared/

## Overview
Extraction epic arising from the 2026-08-08 duplication survey (structural name-collision sweep + 3 parallel body-comparison audits over input/render/core-sim primitives across all 9 games). This is the INVERSE of SH3: where SH3 retires stragglers' re-implementations of code that ALREADY lives in shared, SH4 lifts NEW duplication OUT of the games and into the shared library. Every candidate here was verified by opening and comparing the actual bodies against the ADR-0001 bar (algorithm-identical across >=2 games — a shared name or shape is NOT enough); superficial name-collisions were rejected on inspection (starfields: different algorithms AND different core/shell layers; particle/explosion/debris: bespoke ROM-faithful ports; formatScore: same name, different formatting; single-game distance/collision helpers). Guiding rule (inherited from SH2): share the VERB (the identical mechanism), not the NUMBERS (per-cabinet constants + ROM cue maps stay in the games). SH4-1 and SH4-3 are byte/near-verbatim lifts the code itself flags for extraction; SH4-2 is the highest-VALUE lift (6 games); SH4-4 and SH4-5 are Tier-2 and each carry a DESIGN GATE that must be resolved before implementation. NOTE the cross-link to SH3: SH4-3 creates the shared RASTER integer-scale letterbox that pac-man actually needs, so it supersedes the '@shared/view letterbox' clause of SH3-4 (pac-man's letterbox is the raster fitIntegerScale, NOT @shared/view's DPR/vector letterbox) — sequence SH4-3 before SH3-4 or fold them. OUT OF SCOPE (deferred, too trivial or single-game): the euclidean mod(v,size) one-expression primitive (asteroids/pac-man/red-baron), the rgbCss+Rgb pair (centipede/missile-command, worth it only as a future @shared/color), and intra-game dedup that is NOT a shared lift (asteroids' mod/wrap in bounds.ts+saucer.ts, battlezone's angle-fold triplicated across radar.ts/enemies.ts/saucer.ts). Design spec pending (Architect handoff). Every lifted symbol must be pinned by a shared test, and each adopting game's existing suite must stay green — an extraction that changes a determinism/render output is a regression, not a refactor.
