# Epic SH3 Context

## Title
Shared-module adoption — retire the straggler cabinets' per-game re-implementations of extracted shared code

## Overview
Adoption epic arising from the 2026-08-08 shared-library usage survey (all 9 plugins x 13 @shared modules). SH and SH2 EXTRACTED code into the shared library (math3d/rng/highscore/loop, then font/glow/view/compositor); SH3 closes the loop by RETIRING the per-game duplication the survey found in the three newest cabinets. Survey result: the five originals + centipede are deep adopters (9-13 modules), while joust (3), pac-man (5) and missile-command (2) still hand-roll code that already lives in @shared. Guiding rule (inherited from SH2): share the VERB (the identical mechanism), not the NUMBERS (per-cabinet constants + exotic ROM timebases stay in the games). This epic targets ONLY duplication that exists TODAY and is byte/algorithm-identical to a shared module: joust's inlined mulberry32 (a self-documented byte-for-byte copy of @shared/rng behind a stale pre-collapse 'no git-URL pin yet' comment), and the raw requestAnimationFrame loops + bespoke canvas-mount/audio-unlock/DPR-letterbox lifecycles that @shared/loop, @shared/host-helpers and @shared/view already provide. Every swap of a determinism primitive (rng, loop) MUST be pinned by a test proving the observable sequence is unchanged, so demos/replays/high-score seeds do not drift. Design spec pending (Architect handoff). OUT OF SCOPE: (1) feature-gated shell furniture on missile-command and pac-man — @shared/pause, @shared/name-entry and @shared/highscore presuppose a pause/attract/high-score FEATURE that mc5's charter defers to mc6/mc7, so adopting them is 'build the future feature ON shared', not 'retire duplication', and belongs to those epics; (2) math3d/glow/synth non-use, which is correct by ADR-0001 (3-D-only, vector-only, and the deliberate synth-vs-audio fork respectively); (3) red-baron's loop/view gaps, deferred pending a determinism-risk assessment of its citation-gated core.
