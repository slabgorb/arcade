# Epic jt10 Context

## Title
Joust cabinet lifecycle — attract/title, 1P·2P select, game over, high-score, and Joust's two fonts

## Overview
The cabinet shell Joust is missing: main.ts boots straight into a seeded wave-1 game with no attract/title, no 1P/2P start select, no game-over screen, and only an 8px-monospace dev overlay. This epic adds the outer lifecycle as a new third core tier (cabinet.ts) above the existing sim (frame.ts) and session (game.ts) tiers, mirroring tempest's Mode and hinged on the GOVER tri-state game.ts already models (jt4-4). It also ports Joust's own TWO fonts from MESSAGE.SRC — FONT35 (3x5, tight: scores/CREDITS) and FONT57 (5x7, stylized: banners/title) — as pure core data plus a shell raster text renderer (NOT the shared vector font). Reuse-first: GOVER/out/lives/settleGameOver, demo.ts self-play, @shared/highscore, and the atlas/blit path already exist. Font-first ordering: jt10-1 blocks all; jt10-2 gates the screens; jt10-7 needs gameover reached. Full design, ROM citations, and open quarry items (JOUST logo geometry, title revision phrasing, attract page order/timings) in docs/superpowers/specs/2026-08-07-joust-cabinet-lifecycle-design.md. ad1-4 (joust attract simulation) is superseded by jt10-4 and canceled in ad1 with a pointer.
