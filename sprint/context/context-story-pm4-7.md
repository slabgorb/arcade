## Problem
Today the game advances levels and respawns instantly with no pause/transition. The level-clear reintroduces a full-screen white strobe (accessibility hazard). This story introduces freeze windows with static frames for both transitions, replacing the instant behavior.

## Technical Approach
1. **RED phase:** Pin the current instant advance/respawn behavior with failing tests; cite the ROM READY! and death-delay cadences (pacman.asm)
2. **GREEN phase:** Wire the freeze transitions in game.ts:
   - Detect level-cleared condition → enter level-clear phase
   - Detect pac-died with lives>0 → enter dying phase
   - Implement freeze timers (ROM-cited, seeded, frame-count based, no clock)
   - Advance to ready after timer expires
3. **Verify:** Purity tests green, no full-screen flashing, citations.test.ts gates all new constants

## Scope
- **In scope:**
  - Wire level-clear -> ready transition with freeze timer (ROM-cited cadence)
  - Wire dying -> ready transition with freeze timer (ROM-cited cadence)
  - Core implementation only (game.ts)
  - Seeded frame-count timers (no clock)

- **Out of scope:**
