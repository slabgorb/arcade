## Technical Approach
See the session file's six measured facts. Key points:
- **Extract the function + `Fit` interface, not the file** — centipede's `layout.ts`
  also holds gun/cell helpers that stay put (Fact 1).
- **Parameterize on logical dimensions** — the fn reads module-scoped `LOGICAL_W/H`,
  which differ per game (centipede hardcoded, pac-man derived from `MAZE`). The shared
  export must take `logicalW`/`logicalH` as arguments (Fact 2). Chief design decision.
- **New export, distinct from `letterbox()`** in `src/shared/view.ts` — do not merge
  into or overload the existing DPR/aspect-fit `letterbox` (Fact 3).
- **Expect the SH3-6 wiring test to redden** when pac-man's import is re-pointed to
  `@shared/view` — UPDATE the anchor, do NOT restore the local import (Fact 5).
