# Epic sc1 Context

## Title
Shell convergence — compositional host helpers across the seven games

## Overview
Named out of scope by the plugin-host design in its own words (section 4.3: 'Shell convergence becomes its own follow-up epic, planned against the real matrix above rather than an assumed one'), and promoted here from the single 8-point story it had been parked as. The seven games' main.ts files share almost nothing structurally even though each mounts a canvas, unlocks audio on a first gesture, installs a pause toggle and wires a high-score store. The migration deliberately touched none of them — a Global Constraint forbade modifying any game's main.ts beyond an import-path rewrite, precisely so the collapse could not be blamed for a behaviour change. That constraint expired with the migration; this epic is what it was protecting. The design's section 4.3 carries the MEASURED adoption matrix (which game uses resizeToDisplay vs its own letterbox vs nothing, which unlocks audio, which has an Esc pause, which uses the shared loop) and that matrix is this epic's input — it is not a mandate to give every game every helper, and a game with no pause today must not grow one here. THE HARD CONSTRAINT IS TIMING FIDELITY: centipede and joust run the cabinets' own cadences gated against original source, so a helper that changes when a frame starts or how input is sampled is a regression even when every test stays green. Land helpers behind the games rather than in front of them, and adopt one game at a time so a cadence change has exactly one suspect.
