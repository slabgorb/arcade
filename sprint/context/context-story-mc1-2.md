## Technical Approach
_Approach hints for TEA/Dev. The story title above defines the intended behavior._

- **Core/shell split (the one load-bearing rule).** `plugins/missile-command/src/core/field.ts`
  = pure fixed-layout DATA (no clock, no `Date`, no `Math.random`, no canvas). The plugin
  already carries a core-purity source scan copied from joust — keep field.ts on the pure side.
  `plugins/missile-command/src/shell/render.ts` = raster painting only.
- **The numbers live in the SOURCE, not the brief.** The brief's "Cited constants" table
  (`plugins/missile-command/docs/rom-study/brief.md`, ~line 85) lists NCITY/NMISBA with values
  but shows the CITY-coords row as a label RANGE (`—`), not enumerated numbers. Read the actual
  per-city H/V values from `reference/source/W3COMN.MAC:123-145`.
- **RADIX discipline.** `W3COMN.MAC` sets `.RADIX 16` at :1 — bare numbers are HEX; a trailing
  period means DECIMAL (e.g. `MAXMIS=10.` decimal vs `CITY2H=0B4` hex). Every constant carries a
  source citation.

## ⚠ Gotcha — the source file greps false-empty without `-a`
`reference/source/W3COMN.MAC` contains a stray non-text byte, so `file` reports "data" and a
plain `grep "CITY" W3COMN.MAC` returns **nothing** — a false zero. Use `grep -a` / `grep -aniE`
to read or cite it. A zero-hit grep here is a claim about the missing flag, not about the file.
