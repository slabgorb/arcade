## Problem
The seam only — this story ships NO baked samples and NO R2 uploads, so it cannot be blocked by asset production. It answers one open question first, then builds the same three pieces the sibling games share. THE QUESTION: joust consumes nothing from @arcade/shared today — not rng, pause, esc-overlay, highscore or name-entry — where every other game consumes between four and nine subpaths. That is either a deliberate standalone posture or an accident of joust being the newest repo, and this story records which before adopting @arcade/shared/audio. If the ruling is adopt, joust gains its first shared dependency and the usual pin-and-bump ceremony applies; if the ruling is stay standalone, the story implements the same shape locally and says why. Do not assume either. THE PIECES: src/core/events.ts, a discriminated union of gameplay moments emitted as DATA on the step result, never as callbacks, so the core stays pure and jt2's seeded determinism replays still reproduce bit-for-bit — joust's replays are a real constraint here, not a formality. The sim already produces every moment worth a cue: the flap, a lance joust won or lost, a rider unhorsed, an egg laid, collected or hatching, the buzzard, the pterodactyl arriving, the lava troll's grab, the wave clearing, a life lost. Then src/shell/audio.ts with the manifest and channel map, and src/shell/audio-dispatch.ts with a never exhaustiveness guard so a later event kind added without a cue fails the build. GROUND TRUTH IS A DIFFERENT QUARRY: joust is Williams, not Atari, so the five vector games' POKEY lineage does not carry over and neither does centipede's. Establishing what JOUSTRV4.SRC and the machine's sound board actually specify is part of this story; cite it or record explicitly that a cue is an invention pending source.

## Acceptance Criteria
- The shared-versus-standalone question this story was written to rule on is recorded as MOOT, not re-litigated: the 2026-07-30 monorepo collapse removed the package boundary, so the engine imports @shared/audio directly with no pin, no git-URL dependency and no version bump.
- core/events.ts defines the event union and the sim emits it as data; joust's purity scanner still passes and no DOM, clock or randomness entered the core.
- jt2's seeded determinism replays still reproduce bit-for-bit — the event channel adds no RNG draw and no ordering change, and a test pins that.
- shell/audio-dispatch.ts maps every event kind to a cue behind a never exhaustiveness guard, so adding a kind without a cue is a compile error.
- Each cue in the manifest either cites JOUSTRV4.SRC or the sound board, or is explicitly marked an invention pending source — no cue is silently fabricated as authentic.
- No .wav is committed and no R2 upload is claimed by this story; the story states plainly that joust is still silent when it closes.
