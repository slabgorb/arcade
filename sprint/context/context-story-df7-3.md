## Technical Approach
The mc6-4 / pm4 self-play analog — a deterministic auto-player over the **real** sim.

- **Drive the real sim, don't fork a demo path (the jt13 lesson).** A pure, seeded,
  clock-free attract driver in `src/core` produces ship inputs (thrust / reverse / fire /
  smart-bomb) fed to the **real df3 sim** during `phase === attract`, so the attract screen
  shows actual gameplay. Do not build a separate scripted demo renderer.
- **Any input exits.** The first real player input transitions `attract → setup` (df7-1).
- **Deterministic.** Same seed replays the same attract bit-for-bit (purity.test.ts green);
  no `Math.random`, no clock.
- **Cite the ROM attract display** `HALDIS AMODE1.SRC:375` (reached `HALL13 :230`); constants
  → `claims/*.json`. Colour by df2 palette index.
- **ADR-0005.** The demo's smart-bomb visuals route through the df4-2 effect policy — no
  full-frame strobe (Decision B); the guard stays green with the demo live.
