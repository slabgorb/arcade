## Problem
MIRV (Multiple Independent Reentry Vehicle) warheads must split from a parent ICBM when it enters the height band [128,160]. Faithful REV-01 implementation requires:
- A pure function to detect an in-flight ballistic ICBM whose head is in the MIRV band
- A split function that forks into ≤3 child ICBMs, each retargeted at a live structure
- Wiring into `stepGame` to activate the split after enemy flight, suppressed when ≥12 explosions are live

## Technical Approach
1. **Create `src/core/mirv.ts`** with two pure functions:
   - `mirvEligible(icbm: Icbm): boolean` — returns true for ballistic ICBMs with head in [128,160], false for arrived or out-of-band
   - `mirvSplit(parent: Icbm, liveTargets: Structure[], rng: Rng): Icbm[]` — forks into ≤3 children, each at parent origin, retargeted

2. **Wire into `stepGame`** (game.ts play branch):
   - After enemy flight, before damage calculation
   - Check `mirvEligible` on each in-flight ballistic ICBM
   - Call `mirvSplit` if conditions met
   - Suppress split while `explosions.length >= 12`
   - Add children to the active ICBM array

3. **Purity & Citations:**
