## Problem / Background
Millipede core (`plugins/millipede/src/core/`) has the sim reducers, high-score table,
Conway growth, waves, etc., but **no game-level phase machine**. Nothing yet models the
cabinet's overall lifecycle — attract → play → death → game-over — that the ROM drives
from **MLATR** (MODE FE = initialize, MODE FF = execute; MLATR.MAC:126/313) with the
attract-mode action at MLATR.MAC:21.

This story ships the **PURE, UNWIRED** phase machine only (the pm4-5 model): a
deterministic, frame-count-driven state machine in `src/core/`, fully unit-tested, with
**no runtime wiring**. Wiring the frame loop, input, and render/audio to it is **ml7-2
and is OUT OF SCOPE here**.
