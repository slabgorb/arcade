## Background

The picture EPROMs from the MAME milliped set (136013-106.p5 and 136013-107.r5, 2048 bytes each) have been sourced and are available at `~/roms/milliped.zip`. The story must vendor these bytes into the repo under a byte-equality gate, licence-walled, following the precedent set by centipede and pac-man.

**ROM Source:** `~/roms/milliped.zip` contains:
- `136013-106.p5` — 2048 bytes
- `136013-107.r5` — 2048 bytes

**Vendor Model:** Follow centipede's pattern exactly:
- Binaries stored in `reference/original-source/millipede/` (gitignored, licence-walled)
- Byte-equality gate with `vendoredAvailable = existsSync(...)` skip-if-absent guard (see `plugins/centipede/tools/pictures-bake/bake-contact-sheet.test.mjs` lines ~40–50)
- Test runs GREEN against real bytes when ROM files are present

**Provenance:** CRC32 and byte hashes sourced from MAME milliped driver in `~/Projects/mame/src/mame/atari/centiped.cpp` (GPL, cited in prose only, never copied). Provenance recorded in `rom-study/claims/graphics.json` per the pac-man model (`plugins/pac-man/docs/rom-study/claims/graphics.json`).

**Scope Boundary:** This story vendors + gates the bytes only. The 8x8 planar decode primitive (ml2-2), RAM-colour palette seam (ml2-3), and bake-to-*-data.ts + visual playfield (ml2-4) are separate stories.

## Technical Approach

1. **Extract and Vendor:** Extract 136013-106.p5 and 136013-107.r5 from `~/roms/milliped.zip` and place them in `reference/original-source/millipede/`, gitignored and licence-walled (never committed to the repo).

2. **Byte-Equality Gate:** Create a test (pattern: `plugins/centipede/tools/pictures-bake/bake-contact-sheet.test.mjs` or `plugins/pac-man/tools/bake-graphics.mjs`) that:
   - Checks for vendor availability via `existsSync(...)`
   - Skips test if files not present (vendoredAvailable guard)
   - Reads byte-exact content when files are present
   - Verifies byte equality against a known hash/CRC from MAME

3. **Provenance Recording:** Extract CRC32 and byte hashes from MAME's Millipede ROM definitions (`~/Projects/mame/src/mame/atari/centiped.cpp`, `ROM_START( milliped )` — there is no `milliped.cpp`) and record them in `plugins/millipede/docs/rom-study/claims/graphics.json` (per `plugins/pac-man/docs/rom-study/claims/graphics.json` structure).

4. **Citation Gate Validation:** Ensure the new claims pass the citation-gate test (`plugins/millipede/tests/audit/citations.test.ts`, inherited from ml1) without introducing uncited constants.

5. **Verification:** Run the byte-equality test GREEN against the vendor binaries. Confirm `citations.test.ts` and `purity.test.ts` remain green.
