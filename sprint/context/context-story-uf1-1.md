## Problem
planeFires(level, frame, roll) — red-baron/src/core/enemy.ts:789 — is ported from R2BRON.MAC:4798-4807, covered by tests/core/enemy-fire.test.ts (AC-8, the divide-by-2 FRAME cadence over the PLNLVL level gate) and tests/core/blimp.test.ts, and has ZERO production callers. main.ts:632 states it plainly: 'The blimp is the modelled enemy shooter; plane fire (planeFires) is not yet wired into the shell loop, so it stays silent for now.' Consequence: all three player-hit emission sites in main.ts (:557, :602, :750) are CRSHSN collision crashes, so the pilot is currently immortal to enemy gunfire — the game's central threat does not exist. The blimp path is the working reference: main.ts:742 latches enemyFiring for the SN-017 gun cue when blimpFires(simFrame, level) is true, and :747 rolls BLIMP_HIT_CHANCE against a dedicated blimpRng before calling the rb2-9 loseLife damage channel, guarded by dying === null and not gameOver. Mirror that seam for planes. Note red-baron has no single stepGame: the calc-frame loop in main.ts assembles the GameEvent list itself, and the roll must come from a seeded Rng so the URL seed param (main.ts:461) still replays deterministically. Watch the level gate — planeFireChance returns 0 below level 4, 0.5 at level 4, 1 above, so a wave-1 playtest will correctly show nothing.

## Acceptance Criteria
- planeFires is called from the calc-frame loop for each live plane, with its roll drawn from a seeded Rng so a given seed param replays the same fire pattern.
- A plane's fire can cost the pilot a life through the same rb2-9 loseLife channel the blimp uses, guarded by dying === null and not gameOver, and emits a player-hit GameEvent.
- A plane firing latches enemyFiring for the SN-017 gun cue, matching the blimp's rb4-10 behaviour that every shell rattles the same gun.
- The level gate is preserved end to end: no plane fire occurs below level 4, and level 4 fires on roughly half its eligible frames.
- A test proves the wiring non-vacuous by mutation — disabling the new call site reddens a test that asserts player damage from plane fire, not merely that planeFires returns true.
