## Problem
Egg and survival rounds (and all wave types) do not announce themselves on screen. Core HAS the seam: wave.ts waveBeats() returns ROM WAVMSG labels per resolved type (INTRO1/2, COOP1/2, SURV1, GLAD1/2/3, EGG1, PTER1), but (a) they are converted to {kind:'beat',message} events in ONLY ONE place — sim.ts:1519, the wave-1 demo seed — the real wave-advance path emits no beats; and (b) nothing in src/shell or main.ts consumes 'beat' events, so nothing paints them, and there is no label->display-text map (SURV1 -> on-screen phrase). Wire the message beats: emit beats on real wave advances, add the label->text mapping from the ROM WAVMSG strings, and render them on the shell with the ROM timing (~1s beats, SHELL owns durations per wave.ts:352-353 #180/6,#90/6 JOUSTRV4.SRC:2045,2601).
