## Technical Approach
Decision C: the hall of fame is `@shared`, **consumed**. df5-6 already shipped the pure
board (`core/highscore.ts`) + one-origin localStorage (`shell/highscore.ts`). df7-4 wires
the flow and renders the display.

- **The flow.** On `game-over` (df7-1), a qualifying score enters `@shared/name-entry` (the
  same asteroids / missile-command / pac-man shape) and is committed to the df5-6 board via
  `@shared/highscore`; then the machine returns to `attract`. A non-qualifying score skips
  entry and returns to attract. No bespoke entry UI, no new persistence.
- **The display.** Render the hall-of-fame screen in the shell reading the df5-6 board —
  `HOFIN` initials display (`AMODE1.SRC:244`), add-score/initials (`:270`). The ROM
  stick-driven initial entry (`HOFUD :325`) maps to `@shared/name-entry` input; underline
  `HOFUL :185`; entry banner `HALLOF :119`. Constants → `claims/*.json`.
- **ADR-0005.** No full-frame strobe (Decision B); colour by df2 palette index.

## Scope
