## Overview
First Millipede epic and phase 1 of the raster-cabinet build (docs/playbooks/next-sprite-game.md). Produces plugins/millipede/docs/rom-study/ — the single-sided ground-truth dossier (brief/glossary/subsystems/open-questions + claims/*.json) — plus the boot-stable four-file scaffold and the citation gate + src/core purity test, folded into one epic as pac-man's pm1 did. Millipede (Ed Logg, Sept 1982) is a revised-Centipede board assembled with the SAME toolchain (MAC65, .MAC, .RADIX 16), so this is a rom-source-study SIBLING case: COIN65.MAC is byte-identical to centipede (verified by diff — cite, don't re-study), radix + timebase ARCHITECTURE transfer with re-verification, but the exact refresh, the CONWAY Life field (Mark Cerny's Game-of-Life mushroom/DDT growth — no centipede analog), the richer bestiary (beetle/spider/dragonfly/mosquito/earwig/inchworm/bee/DDT), and RAM-driven colour (no colour/sync PROM in the ledger; MLIRQ.MAC:242 CLRCH COLOR RAM INITIALIZATION) are genuinely new and get fresh study. Source ALREADY vendored: reference/original-source/millipede/ @ historicalsource/millipede 29f3e05 (docs/reference-sources.md). Gaps found by checking INSIDE other files, not just the file list: MILLI.DOC design doc is absent AND not embedded (a secondary-doc gap, NOT a ground-truth gap — scoring is the source table PTS MLDEF.MAC:398, difficulty MLDEF.MAC:88,91); 368XX.SB2 picture source absent AND not embedded (MILLI.LDA is the CPU program image only — picture pixels come from the MAME milliped set 136013-106/107). Citation vocabulary fixed: millipede/<FILE>.MAC:<line> into the vendored tree; nothing downstream introduces a src/core constant without a claim gated by citations.test.ts, and purity stays green. Secondary source MAME milliped.cpp wins ONLY on board facts the source never states (master clock, exact refresh, geometry, colour wiring) — cited in prose, never copied (GPL). Design + full cabinet roadmap: docs/superpowers/specs/2026-08-11-millipede-cabinet-roadmap-and-ml1-design.md. Sibling oracle: plugins/centipede/docs/rom-study/ (copy its layout + tools/audit/check-citations.mjs, drop the ours side). OUT OF SCOPE: graphics-ROM decode (ml2), core sim incl. the CONWAY Life field (ml3), sound (ml4), phase machine/wiring/HUD (ml5), hardening (ml6+).
