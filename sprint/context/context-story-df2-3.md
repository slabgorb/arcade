**RED artifacts already committed (the spec):**

  render contract (red until the module exists).

**ROM format (verified this session, cite `defender/MESS0.SRC:<line>` in comments):**
- `CHRTBL` (`:441`) — 4-byte descriptor records `FDB $WWHH,<ptr>`; **WW = width
  (high byte), HH = height (low byte)**, big-endian; the ROM's `TEXT7B` (`:804`)
  strides by 4 and `ADDA ,Y` (:812) advances the cursor by WW.
- Cell data = **WW × HH bytes** at the pointer. **Trap:** `SPACE` is `SPACE EQU *`
  (`:490`) aliasing the oversized all-zero `BLANK` block (`BSZ 3*8` = 24 bytes) — a
  glyph's effective cell is `width×height` bytes **sliced from the start** of the
  (possibly longer, EQU-aliased) block. The test-side `cellBytes()` already does this.
- Invalid char → `?` (`TEXT7A`, `:803`, `LDB #3`). Default char spacing `$01` (`:747`).

**What GREEN (Yoda / Dev) ships:**
1. `scripts/transcribe-charset.mjs` — the transcribe tool. Its OWN reading of
   `MESS0.SRC` (do not consume the test reader). Emits the generated data.
2. `plugins/defender/src/core/charset.ts` — PURE core (no shell/canvas/fs/clock;
   `tests/purity.test.ts` + a focused scan enforce it). Exports:
   - `CHARSET: readonly Glyph[]` — `{ name, char, width, height, encoding:'raster',
     bytes, source:{file:'MESS0.SRC', label} }`; `source.label` is the **CHRTBL ptr**.
   - `glyphForChar(ch): Glyph | undefined`.
   - `blitGlyph(fb, glyph, x, y, colorIndex)` — pure raster stamp of the glyph's
     foreground pixels as `colorIndex` into the framebuffer, **clipped**; refuses a
     non-`raster` encoding.
   - `writeText(fb, text, x, y, colorIndex, spacing?)` — lays a string left-to-right,
     advancing the cursor; space draws nothing; unsupported char → `?`.
   - Derive the exact byte→pixel unpacking (nibble order) yourself; the blit tests
     are packing-agnostic on purpose (df2-6's visual playtest confirms orientation).

## Acceptance Criteria (encoded as the committed RED tests)

1. **Independent reader gate** — every glyph in `CHARSET` re-derives byte-for-byte
   from its cited `MESS0.SRC` label and its width/height agree with the `CHRTBL`
   descriptor; any mismatch is refused. (`charset-gate.test.ts`)
2. **Generated module shape** — non-empty; every glyph `encoding:'raster'`,
   `bytes.length === width×height`, all bytes integer 0–255; covers A–Z, 0–9, space.
3. **Independence** — nothing under `src/`/`scripts/` imports the test-side reader.
4. **`blitGlyph`** — blank draws nothing; a letter lights foreground cells **only**
   in the passed colour index (colours never invented); distinct letters differ;
   foreground stays in the glyph's row band; out-of-bounds is clipped, not crashed;
   a non-raster block is refused.
5. **`writeText`** — a single char equals a direct `blitGlyph`; later chars sit to
   the right; a space advances without drawing; a known message renders; unsupported
   char → `?`.
6. **Purity + no invented colours** — `src/core/charset.ts` passes the purity scan
   and contains no `#rgb`/`rgb()` colour literals.
